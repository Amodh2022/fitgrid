# Benchmark results — 2026-09-28

Three runs on the same machine: **before** the fixes; **after** the fixes that stopped sorts, filters and live updates re-measuring every column, kept laid-out text across data updates, and read sort keys once per row; and **after background sorting**, where a sort of 50,000 rows or more runs on another isolate. In the last run, "longest UI stall" is the longest the UI thread went without returning to the event loop during the sort — the number that decides dropped frames.
