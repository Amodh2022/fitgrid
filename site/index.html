The fast Flutter data table that measures your content

A Flutter data grid that sizes columns from what's in them instead of making you guess widths, and paints cells instead of building a widget for each one. It scrolls a million rows as smoothly as a hundred.

Why it's fast

The work tracks the viewport, never the dataset

Same viewport, a thousand times the data, the same amount of work.

Columns measure their content

No width arithmetic. Each column sizes itself from its text, with clamps, flex and fixed widths when you want them. Measurement samples the longest candidates, so it stays fast on huge datasets.

Cells are painted, not built

A block of cells is one render object with cached text painters. Real widgets are still there for the cells that need them, and are built only while visible.

Quick start

A grid in a dozen lines

  1. Add the packageIt has no dependencies beyond Flutter.
  2. Describe your columnsGive each one a stable id and a value. There's no width arithmetic.
  3. Hand it your rowsSorting, selection and virtualization come built in.
FitGrid<Employee>(
  rows: employees,
  columns: [
    FitGridColumn(id: 'name', label: 'Name',
        value: (e) => e.name, sortable: true),
    FitGridColumn(id: 'role', label: 'Role',
        value: (e) => e.role),
    FitGridColumn(id: 'salary', label: 'Salary',
        value: (e) => '\$${e.salary}',
        alignment: FitGridAlignment.end),
  ],
)
flutter pub add fitgrid_table
